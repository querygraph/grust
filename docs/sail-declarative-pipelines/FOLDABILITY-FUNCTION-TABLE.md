# Catalyst foldability of every Sail scalar function name

Read-only companion to `FOLDABILITY-PROVENANCE-REVIEW.md`, requested in
CF-0312 for the expression-local marker (F6). For each name in Sail's scalar
function tables (`crates/sail-plan/src/function/scalar/*.rs` at
`15fd1888c`, 437 names) it gives the Catalyst expression Spark 4.2.1
(`617618396`) registers for that name and the rule by which that expression's
`foldable` is computed, which is what `IdentifierResolution.evalIdentifierExpr`
checks after `prepareForEval`. The last column is what a constant context in
Sail must do so that the final `require_constant_expression` check agrees with
Spark.

## Method

Generated by `handoff-tools/fable/foldability_table.py` from `git archive`
extracts of the two pins (Spark `catalyst/expressions` plus
`FunctionRegistry.scala`; Sail `function/scalar`). The rule is resolved in this
order:

1. an `override … foldable =` on the class itself (`true` → always,
   `false` → never, `child.foldable` / `left && right` / `children.forall` →
   children);
2. a marker trait anywhere in the ancestry: `Unevaluable`, `Nondeterministic`
   (including `Stateful`), `Generator`, `HigherOrderFunction`,
   `UserDefinedExpression` → never (`Expression.scala:436,532`,
   `generators.scala:58`). These are `final override`s, so they win over an
   inherited `UnaryExpression` rule wherever they sit in the linearization
   (`TimeWindow` is `UnaryExpression with … Unevaluable` and is never foldable);
3. an inherited `foldable` override (`CurrentTimestampLike`,
   `LeafMathExpression`, `UnaryExpression`, `BinaryExpression`, …);
4. for `RuntimeReplaceable`, the replacement: a body mentioning `RaiseError`
   or `Rand` → never; `StaticInvoke`/`Invoke` → children, because
   `InvokeLike.foldable` is children foldable and deterministic and a trusted
   type (`objects/objects.scala:74–75`); a constructor-built replacement
   (`Nvl` → `Coalesce`, `TryX` → `TryEval(X)`, `EqualNull` → `EqualNullSafe`,
   `Extract`, `StringTrimBoth`, `NullIfZero`, …) → children, hand-read;
   XPath evaluators → children; `TryReflect` → never;
5. otherwise the `Expression.scala:104` default, which for the classes left
   is always a children rule through `UnaryExpression`/`BinaryExpression`.

Hand-read exceptions encoded in the script: `UnaryPositive` (replacement is
the child), `ToTime`, `ToBinary`, `ParseToDate`, `ParseToTimestamp`,
`Collation` (deterministic wrappers), `Uniform` (replacement multiplies by
`Rand`), `SparkVersion` (replacement is a childless deterministic
`StaticInvoke`, so `version()` is foldable; the review's F3 said "foldable"
for the right reason but the wrong mechanism, there is no override). Registry
builders (`XExpressionBuilder`) are mapped to the expression they build.

Sail lowerings already known to be `Volatile` (so the final check rejects
them without a mark): `input_file_block_length`, `input_file_block_start`, `input_file_name`, `monotonically_increasing_id`, `rand`, `randn`, `random`, `randstr`, `shuffle`, `spark_partition_id`, `uniform`, `uuid`. Names Sail
marks by its higher-order-function list at `expression/function.rs:82`:
`aggregate`, `array_sort`, `exists`, `filter`, `forall`, `map_filter`, `reduce`, `transform`, `transform_keys`, `transform_values`. Names Sail already wraps in
`non_foldable`: `current_catalog`, `current_database`, `current_schema`, `current_timezone`, `current_user`, `session_user`, `user`.

parser-level forms (`struct`, `when`, `case`, `timestampadd`, …) and carry no
Spark foldability of their own; the expression they resolve to decides.

Consequences for F6: the marker is needed for 5 more builtins
(`assert_true`, `json_tuple`, `raise_error`, `window`, `window_time`); every other non-foldable name is either already wrapped, marked by
the higher-order list, or lowered to a `Volatile` function. The
8 always-foldable names must never be marked,
including the four clock functions, whose `Stable` lowering the final check
already admits. `window`/`window_time` are analyzer-rewritten in Spark and
never foldable; in a constant context Sail must mark whatever they lower to.
