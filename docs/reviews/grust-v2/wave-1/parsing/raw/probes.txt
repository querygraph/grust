--- legacy string-scanning write path vs typed parser

    CREATE (n:`A;B` {id: 'x'})
    typed parser: Ok(())
    write planner: Err(CypherSyntax("[gql:syntax] unterminated quoted identifier at line 1, column 11 (bytes 10..12)"))
keyword inside a backtick property name
    MATCH (n:Person {id: 'p1'}) SET n.`x CREATE y` = 1
    typed parser: Ok(())
    write planner: Err(CypherSyntax("unsupported writable Cypher MATCH pattern suffix: SET n.`x"))

    MATCH (n:Person {id: 'p1'}) SET n.x = 1
    typed parser: Ok(())
    write planner: Ok(1)
