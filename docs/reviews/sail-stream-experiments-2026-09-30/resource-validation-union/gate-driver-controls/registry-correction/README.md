Ordinary and saturated tests retain the original Cargo invocation/context and must use that pinned executable, report a complete unfiltered 51-pass summary with every other outcome count zero, and preserve the executable hash. All 45 Argentea passes follow from that complete inventory, not interleaved status lines.

The synthetic registry does **not** replace the real registry capture required in the retry. No Cargo, native executable, SQL, remote operation or Sail source change was performed for these controls.
