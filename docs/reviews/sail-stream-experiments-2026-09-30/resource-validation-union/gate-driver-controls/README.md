# Union gate driver preparation

The final frozen [driver](final/run_gate.py) is SHA256 `31d5f6b3a41f796e0bbc91171df70cbeac59692ed9ffbb7ca4ccd67dd0674b76`. Its [three cleanup controls](final/receipt.json) pass: an already-finished child, an active child, and an exited leader whose remaining child ignores SIGTERM. The latter requires SIGKILL. These controls use test-local TERM/KILL grace periods of 0.2/3 seconds; the production driver uses 30/10 seconds. They run only `stop_group`, with no Cargo, SQL server, Sail source change or runtime qualification.

[Attempt 01](attempt01/receipt.json) failed when macOS returned EPERM while a process group disappeared; its cleanup repeated the error. The exact driver is retained. Its original inline tool exception is [transcribed](attempt01/transcribed-tool-error.txt), explicitly not a contemporaneously saved process log. The [inline control source](attempt01/transcribed-control-source.txt) is likewise explicitly transcribed from the tool invocation. Child PIDs were not captured in that first tool output. [Attempt 02](attempt02/receipt.json) proves polling/reaping the leader first is insufficient: it also hit EPERM, and its recorded direct children were reaped by the fixture cleanup. No orphan fixture was started in either failed attempt.

[Attempt 03](attempt03/receipt.json) passes after adding a successful `ps` PID/group inventory fallback. The [final control](final/receipt.json) repeats after requiring that inventory to be nonempty and contain the driver. EPERM itself never proves absence. Only directly owned children are reaped; process-group absence and the orphan PID's absence are recorded separately. Successful selected-group inventory observations contain no command arguments or environment. Test code is retained beside the receipts; transient process fixtures are not copied.

The main driver hashes logs/commands and guards all tracked source, index, detached HEAD and explicit tree before/after every subgate. Candidate and exact modes are distinct. It requires private host/core/native targets, offline nonincremental builds, at least 32 GiB free, strict test inventories, a pinned Python 3.12.8, the pinned SQL helper and the Cargo-identified new CLI artifact. Its gate has not been launched by this preparation work. Root owns formal gate, conditional commit and delivery.
